# Symmetry-invariant-Tractable-Generative-Models

This repository contains the code implementation of experiments performed in my [MSc Thesis](https://drive.google.com/file/d/1xf-mpUtyQ5JmpUN9j38AfD1LUt68VfwG/view). We impose translation invariance in Tractable Generative Models (MADE, PCs, GLOW) to empirically answer the open question as to whether it enhances generalization or not.
